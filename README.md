# Gahoole

パソコンの中のファイルを読んだり書いたりできる AI アシスタントです。
ターミナル（黒い画面）で動きます。

API キーは要りません。ブラウザを裏で立ち上げて Google の AI モードに
質問しているので、無料で使えます。

```
$ gahoole
› 売上.csv を地域別に集計して Excel にして

  ├ read_file  売上.csv
  ├ run_command  python3 …
  └ list_files
  turn done · 4 tool calls · 17.3s

売上_集計.xlsx を作りました。東京 260、大阪 200、福岡 135 です。
```

## 必要なもの

- **Node.js 20.6 以上** — 入っていなければ <https://nodejs.org> から
  「LTS」と書いてある方をダウンロードしてインストールしてください。
- インターネット接続
- ディスクの空き 500MB ほど（初回にブラウザを取ってきます）

Google のアカウントもログインも要りません。

## インストール

ターミナルを開いて、次の1行を貼り付けて Enter：

```bash
npm install -g github:net-runners-com/gahoole
```

1〜2分かかります（中で組み立てているため）。

## 使う

作業したいフォルダに移動してから起動します。

```bash
cd ~/Documents/仕事
gahoole
```

**初回だけ2つ聞かれます。**

1. **このフォルダを信用しますか** — Claude Code と同じ確認です。
   ここで「はい」と答えたフォルダの中だけ、ファイルを読み書きします。
   1 を押して Enter。
2. **ブラウザのダウンロード** — 350MB ほど自動で落ちてきます。1〜2分。
   これは最初の1回だけです。

あとは日本語で頼むだけです。`/exit` か Ctrl-C で終わります。

## 覚えておくと便利なもの

| 入力 | すること |
|---|---|
| `/auto <やりたいこと>` | 手順を立てて、最後まで自分で進めます。時間のかかる作業はこれ |
| `/exit` | 終了 |
| `/help` | コマンド一覧 |
| `Esc` | 考えている途中で止める |
| `/clear` | 話の流れをリセット（ファイルは消えません） |
| `/memory` | 前回までに分かったことを表示 |

ファイルを書いたり消したり、コマンドを実行したりする前には毎回確認が出ます。
確認なしで進めてほしいときは `gahoole --allow` で起動してください。

## できること・できないこと

**得意**

- ファイルを読んで、まとめる・変換する・集計する
- CSV から Excel を作る、フォルダの中を整理する
- 決まった手順のある作業を最後まで通す

**苦手**

- **見た目が価値になるもの。** 帳票やシフト表を作らせると、罫線と数式は
  入るのに見出しや凡例が抜けた「骨組みだけ」のものが出てくることがあります。
  そのまま配れる完成品は期待しないでください。
- **長く使い続けること。** 1つのブラウザにつき100回ほど質問すると
  Google に止められます。自動で新しいブラウザに切り替えて続けますが、
  1日中回し続ける用途には向きません。
- **正確さが命に関わること。** 出てきた数字は必ず自分で確かめてください。

## 作ったものはどこに置かれるか

**作業したフォルダの中**に置かれます。信用すると答えたフォルダの外には、
読み書きしません。

設定と記録はホームフォルダの `~/.gahoole/` に入ります。
消したいときはこのフォルダごと消してください。

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| `command not found: gahoole` | インストールをやり直す。Node.js が入っているか `node -v` で確認 |
| ずっと待たされる | 初回はブラウザのダウンロードで1〜2分かかります。2回目以降で遅いときは Esc |
| 「AI Mode returned nothing」 | 質問しすぎです。数分おいてから、または `/clear` してやり直し |
| 答えが的外れ | `/clear` で流れをリセットしてから、もう一度具体的に頼む |
